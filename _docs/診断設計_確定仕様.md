# 診断＋プレゼント教材 設計仕様（確定分）

最終更新：2026-07-31（英語特化に改訂・本番反映済み）

本書は全15LPの埋め込み診断の**確定仕様**。本番LPへ反映済み。
2026-07-31にプレゼントを4科目から**英語1教科・4分野**に絞る改訂を行った（改訂の背景と全変更点は `英語特化_診断改訂案.md`）。

---

## 0. 全体の前提

- 導線：**LP内で診断 → 結果表示 → LINE登録でプレゼント → 体験URLへ**
- **プレゼント＝全LP「教材」に統一**（BOOK/図鑑案は不採用）
  - 理由：図鑑は比較検討モードに入らせ、LINE登録率は上がってもカウンセリング受講率が下がるため
- **教材＝ダウンロード物ではなく、URL遷移でのインタラクティブ学習体験**（実際のFAST-UPの学習環境を体感させる）

### 体験でできること（この4つのみ）
1. **毎日の計画**
2. **独自教材（ライブラリ上）**
3. **ミニ模試**（セクションごとの確認テストをWEB上でクイズ形式）
4. **学習管理**（学習時間・ミニ模試の理解度などを振り返れる）

> 注意：**週1固定面談・FAST-UP AI は体験では提供できない**ため、診断結果の接続先に使わない。

### 最終設問＝英語4分野の判定（グループA＝Q4 / グループB＝Q5・全15LP共通）

| 選択肢（回答者の課題文） | `data-v` | 判定する分野 |
|---|---|---|
| 単語を覚えても、すぐ忘れる | `word` | 英単語 |
| 文法問題で、いつも間違える | `gram` | 英文法 |
| 単語は分かるのに、意味が取れない | `syntax` | 英文解釈 |
| 長文が、時間内に読み終わらない | `long` | 英語長文 |

- **「苦手な分野は？」とは聞かない。** 単語・文法・解釈・長文の区別がつかない受験生が答えられず離脱するため、症状で選ばせてこちらが分野に変換する。とくに英文解釈は自己申告できないので「単語は分かるのに、意味が取れない」で拾う。
- 選択肢は13〜16字に統一（2列ボタングリッドで崩れないため）。
- **LP別の出し分けはしない。** 英語の詰まり方は志望校で変わらず、LP別に変えると8LPで共有する教材ファミリーとの対応が崩れるため。

→ 結果の「最優先課題」を分野別に出し分け。**体験の入口＝その分野の教材ライブラリとミニ模試**。

## 4. 結果の出力構造（全15LP共通・4ブロック）

画面には①〜④の下書きラベルや文字数表記は出さない。見出しは下記のとおり。

```
① 結果            … 合格可能性%（A） or サポートタイプ（B）＋判定文
② 見出し「あなたの現状」      … なぜその結果なのか（約100字）
③ 見出し「これからやるべきこと」 … 次に何をやるべきか（約100字）
④ オファー         … 教材の価値訴求 → LINE登録
```

### ②③の分岐軸（確定・2軸）
- **グループA**：スコア3段階（低〜54／中55〜74／高75〜）**×** 期間2種 ＝ **6パターン**
- **グループB**：4タイプ **×** 期間2種 ＝ **8パターン**
- **期間の定義**：Q2が「3ヶ月以内／4〜6ヶ月」＝**短期**、「7〜12ヶ月／13ヶ月以上」＝**長期**

### 期間によるロジックの違い（重要）
| | ロジック |
|---|---|
| **短期** | 時間がないので**勉強する範囲を絞る**。「出るところだけを勉強する」 |
| **長期** | まだ直前期の「対策」の段階ではない。**志望校に必要な勉強を早くから始める**ほど合格率が上がる |

> 長期側で「志望校の出題に合わせた対策」「対策を行う」は使わない（残り半年でやることのため不自然）。

### ③アドバイスの文章ひな型（山本さん確定）
【指示】→【入試の事実】→【効果】の3文構成。**行動手順（1日1セクション等）は書かない**。
> 例：やることを絞ってください。私大入試で問われるのは、限られた範囲です。出題される範囲から重点的にやることで、最短での合格が可能になります。

理由：直後のオファーで渡すのは**教材そのもの**であり、進め方の管理ではない。行動手順を書くとオファーと噛み合わない。

### 使用禁止の表現（不自然・AI的なため）
積む／積み上げる／積む順番／射程内／完成度／〜が前提になります／見える化／分散／再現できる／定着不足／管理の仕組み
→ 日常の言葉（勉強する・仕上げる・慣れる・決まっている 等）で書く。

### ④オファーの構成
```
タイトル ： {特化ラベル}の英語教材を、体感してみませんか？
サブタイトル： FAST-UP {ファミリー} {分野}　無料プレゼント   ← 分野連動
補足1  ： 英語4分野（単語／文法／解釈／長文）の中から、あなたに必要な〈{分野}〉をお渡しします。
補足2  ： 分野別の一文（下表）   ← 「なぜこの分野の教材が必要か」を教材の価値説明として置く
本体   ： 左＝教材モックアップ画像（後ではめ込み）／右＝チェック3つ
         ✓ 私大専門で7年、{対象}の英語の出題傾向を分析し続けて作成
         ✓ 感動する！圧倒的な分かりやすさ
         ✓ セクションごとの確認テストで、定着まで
CTA    ： LINE登録で教材を受け取る
```
> 「体験できる」等の体験訴求は**書かない**。教材そのものの価値だけを訴求する。
> 4分野用意はあるが、**渡すのは判定された分野1つ**。

#### 補足2＝分野別の一文
| 分野 | 一文 |
|---|---|
| 英単語 | {対象}の英語は、知らない単語が1つあるだけで文の意味が変わります。 |
| 英文法 | 入試の英文法で問われるルールの数は、限られています。 |
| 英文解釈 | 単語も文法も分かるのに読めないのは、一文の構造が取れていないからです。 |
| 英語長文 | {対象}の英語は、配点の大半が長文です。 |

※ 英文法・英文解釈は{対象}を入れない。文法単独問題の出題有無は大学差が大きく、「{大学}入試では文法だけを問う設問が毎年出ます」と書くと事実に反するLPが出るため。

#### 合格可能性への分野の反映（グループAのみ）
| 選んだ分野 | 配点 |
|---|---|
| 英単語 | −6（詰まりが最も手前＝合格までの距離が最も遠い） |
| 英文法 | −4 |
| 英文解釈 | −3 |
| 英語長文 | −1（仕上げ段階＝合格に最も近い） |

旧仕様（英語−6／国語−3／数学−2／社会−1）と増減の幅は同じなので、スコア分布は変わらない。
