# プレゼント教材 一覧（確定版）

最終更新：2026-07-31（英語特化に改訂） ／ この文書が**教材名・必要数の唯一の正**（`診断設計_確定仕様.md` §5 の旧表より優先）。

## 前提

- 各LPの診断の最後で、利用者は**英語の困りごとを1つ**選ぶ（設問「英語で、いちばん困っているのは？」）。回答から**英語4分野**（**英単語 / 英文法 / 英文解釈 / 英語長文**）のいずれかを判定する。
- LINE登録すると、**判定された分野の教材1冊**を渡す。
- 教材は「ダウンロード物」ではなく、URL遷移でのインタラクティブ学習体験（毎日の計画／独自教材ライブラリ／ミニ模試／学習管理）。
- したがって**1LPにつき4分野分の教材が必要**。ただし大学特化以外の8LPは同じ教材を共有する。

## 教材名の付け方

- **大学・大学群特化 7LP**：`FAST-UP {大学}必出 {分野}`（例：FAST-UP 早慶必出 英文法）
- **その他 8LP**：`FAST-UP 私大逆転 {分野}`（例：FAST-UP 私大逆転 英単語）※8LP共通

## 補足・保留

- 旧仕様（英語・国語・社会・数学の4科目）で保留だった「私大文系に数学は不要では」という問題は解消。英語は全私大文系で必須かつ配点最大のため、**32冊すべてに受け取り手がいる**。
- 分野の判定ロジックは各LPの `index.html` 内 `FIELD` 定数と Q4（グループA）／Q5（グループB）。
- 09-march-each を各校別（明治/立教/青学/中央/法政/学習院）に分けるかは未決。分ける場合は教材も校別に増える。
