# 診断＋プレゼント教材 英語特化 改訂案

作成：2026-07-31 ／ 状態：**山本さん承認済み・本番15LP反映済み**（2026-07-31）

プレゼントを4科目（英語・国語・社会・数学）から **英語1教科・4分野** に絞る改訂。
`診断設計_確定仕様.md` と `教材一覧_確定.md` は本書の内容で更新済み。本書は改訂の背景と判断理由を残すための記録。

---

## 1. 何が変わるか（1行）

最後の設問を「一番の苦手科目は？」から **「英語で、いちばん困っているのは？」** に変え、
プレゼントを **英単語／英文法／英文解釈／英語長文** の4分野から1つ渡す形にする。

診断の型（A＝合格可能性4問／B＝塾タイプ5問）、結果の4ブロック構造、設問数は変えない。

---

## 2. 新しい最終設問（全15LP共通）

> **Q4（グループA）／Q5（グループB）：英語で、いちばん困っているのは？**

| 選択肢（回答者の課題文） | `data-v` | 判定する分野 |
|---|---|---|
| 単語を覚えても、すぐ忘れる | `word` | 英単語 |
| 文法問題で、いつも間違える | `gram` | 英文法 |
| 単語は分かるのに、意味が取れない | `syntax` | 英文解釈 |
| 長文が、時間内に読み終わらない | `long` | 英語長文 |

**設計意図**
- 「苦手な分野は？」と直接聞かない。単語・文法・解釈・長文の区別がつかない受験生が答えられず離脱するため、**症状で選ばせて、こちらが分野に変換する**。
- とくに英文解釈は、受験生が自分で「解釈が弱い」と自覚できない。「単語は分かるのに、意味が取れない」はその症状そのもので、選択肢の中で最も自己申告しやすい。
- 全選択肢を13〜16字に揃え、既存の2列ボタングリッドで崩れないようにした。

**LP別の出し分けはしない（全15LP共通）**
英語の詰まり方は志望校で変わらないため。LP別に文言を変えると、8LPで共有している教材ファミリーとの対応が崩れ、管理コストだけが増える。

## 3. 合格可能性への反映（グループAのみ）

苦手科目による減点を、**分野による減点**に置き換える。

| 選んだ分野 | 配点 | 考え方 |
|---|---|---|
| 英単語 | **−6** | 詰まりが最も手前。合格までの距離が最も遠い |
| 英文法 | **−4** | |
| 英文解釈 | **−3** | |
| 英語長文 | **−1** | 仕上げ段階。合格に最も近い |

旧仕様（英語−6／国語−3／数学−2／社会−1）と増減の幅は同じなので、**スコア分布は変わらない**。
一方で「英語のどこで詰まっているかが、合格までの距離を表す」という根拠が明確になり、科目別配点より診断として説明がつく。

## 4. 教材名（8ファミリー × 4分野 ＝ 32冊）

命名規則は据え置き、{科目} を {分野} に置き換える。

- 大学・大学群特化 7LP：`FAST-UP {大学}必出 {分野}`（例：FAST-UP 早慶必出 英文法）
- その他 8LP：`FAST-UP 私大逆転 {分野}`（8LP共通）

分野の表記は **英単語／英文法／英文解釈／英語長文**。参考書の慣例表記であり、4つとも「英」で始まるので教材名として揃う。

| # | ファミリー | 対象LP | 4冊 |
|---|---|---|---|
| 1 | FAST-UP 私大逆転 | 01, 02, 03, 04a, 04b, 10a, 10b, 11 | 英単語／英文法／英文解釈／英語長文 |
| 2 | FAST-UP 早慶必出 | 05-soukei | 同上 |
| 3 | FAST-UP 早稲田必出 | 06-waseda | 同上 |
| 4 | FAST-UP 慶應必出 | 07-keio | 同上 |
| 5 | FAST-UP GMARCH必出 | 08-gmarch | 同上 |
| 6 | FAST-UP MARCH必出 | 09-march-each | 同上 |
| 7 | FAST-UP 関関同立必出 | 12-kankandoritsu | 同上 |
| 8 | FAST-UP 日東駒専必出 | 13-nittokomasen | 同上 |

**制作数は32冊のまま変わらない。** ただし内容は「4教科を薄く」から「英語を4分野に分けて深く」に変わる。
また、旧仕様で保留になっていた「私大文系に数学は不要では」という問題が消える。英語は全私大文系で必須かつ配点最大のため、**32冊すべてに受け取り手がいる**。

## 5. コピーの変更点

| 箇所 | 旧 | 新 |
|---|---|---|
| リード文 末尾 | 結果に合わせて**あなたの苦手科目の独自教材**を無料プレゼント。 | 結果に合わせて**あなたに必要な英語教材**を無料プレゼント。 |
| オファータイトル | {特化ラベル}の**独自教材**を、体感してみませんか？ | {特化ラベル}の**英語教材**を、体感してみませんか？ |
| オファー補足 | このシリーズの全科目の中から、あなたが選んだ〈英語〉をお渡しします。 | 英語4分野（単語／文法／解釈／長文）の中から、あなたに必要な〈**英文法**〉をお渡しします。<br>＋ 分野別の一文（下表） |
| 訴求1 | 私大専門で7年、**早慶**の出題傾向を分析し続けて作成 | 私大専門で7年、**早慶の英語**の出題傾向を分析し続けて作成 |

### オファー補足に足す分野別の一文

「なぜこの分野の教材があなたに必要か」を、教材の価値説明として④オファー内に置く。
②③の字数・構造には手を入れない（確定済みのため）。

| 分野 | 一文 |
|---|---|
| 英単語 | {対象}の英語は、知らない単語が1つあるだけで文の意味が変わります。 |
| 英文法 | 入試の英文法で問われるルールの数は、限られています。 |
| 英文解釈 | 単語も文法も分かるのに読めないのは、一文の構造が取れていないからです。 |
| 英語長文 | {対象}の英語は、配点の大半が長文です。 |

※ {対象}＝私大／早慶／早稲田／慶應／GMARCH／MARCH／関関同立／日東駒専。
※ 英文法と英文解釈は{対象}を入れない。文法単独問題の出題有無は大学によって差があり、「{大学}入試では文法だけを問う設問が毎年出ます」と書くと事実に反するLPが出るため。

### ②③のうち、分野名が入る文

分野名を差し込むだけで従来どおり成立する。1箇所のみ表現を直した。

- 旧：「英語の**よく出るテーマ**から先に仕上げれば、合格点は安定します。」
- 新：「英単語**も、出るところ**から先に仕上げれば、合格点は安定します。」
  → 「テーマ」は長文にしか当てはまらず、単語・文法で不自然になるため。

- 旧：「英語**もそこに絞って**勉強すれば、合格点を確実に超えられます。」
- 新：「英単語**も、早慶で実際に出るところに絞れば**、合格点を確実に超えられます。」
  → 直前の文が「出る形式とテーマ」を指しており、単語には形式がないため。

グループBの結果文（②③）には分野名が入らないので、変更なし。
